Instagram Setup

1
Create a Facebook App
You need a free Facebook Developer App to get an App ID and Secret. This takes 2 minutes and is completely free.
How to:
  1. Go to developers.facebook.com/apps
  2. Click Create App → choose Consumer (not Business)
  3. Add app name → Continue
  4. Go to Settings → Basic and copy your App ID and App Secret
  5. Under Add a Product, click Set Up next to Instagram Graph API
2
Enter App Credentials
Paste your Facebook App ID and App Secret below.
Also add http://localhost:8000 as a valid OAuth redirect domain in your Facebook App under Facebook Login → Settings → Valid OAuth Redirect URIs: http://localhost:8000/api/oauth/instagram/callback
3
Connect Your Instagram Account
Click the button below. A Facebook login popup will open. Approve access — your token will be saved automatically.

YouTube Setup

1
Enable YouTube Data API
Create a free Google Cloud project and enable the YouTube Data API v3.
How to:
  1. Go to Google Cloud Console → YouTube Data API v3
  2. Click Enable
  3. Go to Credentials → Create Credentials → OAuth 2.0 Client ID
  4. Choose Web application
  5. Under Authorized redirect URIs add: http://localhost:8000/api/oauth/youtube/callback
  6. Download/copy the Client ID and Client Secret
2
Enter Client Credentials
Paste your Google OAuth2 Client ID and Client Secret.
Make sure http://localhost:8000/api/oauth/youtube/callback is added as an Authorized Redirect URI in your Google Cloud Console OAuth client settings.
3
Connect Your YouTube Channel
Click the button below. A Google login popup will open. Select your account and approve access — your refresh token will be saved automatically and never expires.
Advanced: Enter tokens manually (if one-click doesn't work)
